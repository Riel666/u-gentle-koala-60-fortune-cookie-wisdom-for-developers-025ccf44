One fortune-cookie line, 70 characters: your future self is already debugging the code you are about to write.

It reads like a real fortune cookie — one short balanced sentence that lands in a single breath — and it says something every developer knows is true: the code you write today becomes the bug you chase tomorrow. The twist is the tense: the debugging has already begun, before a single line is written. Nothing in it repeats a familiar saying, and a tired senior engineer reading it at the end of a long review can only nod.

## Run it

```sh
python3 main.py
# writes /output/entry.txt (70 characters, no trailing newline)
```
